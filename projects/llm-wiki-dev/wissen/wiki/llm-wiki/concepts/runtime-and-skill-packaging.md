# Runtime and Skill Packaging

The ecosystem material shows a shift from one-off prompts to reusable operational packages:
- skill files (`SKILL.md`) with defined metadata and conventions,
- plugin packaging for multiple runtimes (for example Claude, Codex, OpenCode),
- shared references and sync scripts to reduce behavior drift across distributions.

This packaging layer makes the wiki pattern reproducible and portable, not tied to a single agent client.
