⌨️ Essential NVDA Commands

T = Jump to next table
Ctrl + Alt + Arrow Keys = Navigate table cells
Insert + T = Read table title/caption
Insert + F5 = List all tables on page
Escape = Stop reading
Ctrl + Alt + N = Quit NVDA

🧪 Test Protocol

Test 1: Table Discovery (2 minutes)

Instructions:
  1. Open first table in browser
  2. Press T to find table
  3. Listen to NVDA's announcement
  4. Record what you hear
Expected Results:
❌ Original Table: "Table" (no context)
✅ Improved Table: "Table, Demographic and Baseline Characteristics..."

Test 2: Navigation Test (3 minutes)

Instructions:
  1. Use Ctrl + Alt + Arrow Keys to move around
  2. Try to find the mean age for placebo group
  3. Try to find how many males are in each group
  4. Note how easy/difficult this is
Expected Experience:
❌ Original Table: Confusing, unclear relationships
✅ Improved Table: Clear context, easy to understand

Test 3: Comprehension Test (2 minutes)

Close your eyes and answer:
  1. What does this table show?
  2. How many subjects in each group?
  3. What's the average age in placebo group?
  4. Are there more men or women?

🎯 Quick Browser Test (No Download Required)

🚨 Red Flags to Watch For

Signs of Poor Accessibility:
  • Screen reader just says "table" with no description
  • Data cells have no context ("41.2" means what?)
  • Can't tell which column/row you're in
  • Navigation jumps around randomly
  • Complex numbers without explanation
Signs of Good Accessibility:
  • Clear table description immediately
  • All data has obvious context
  • Always know where you are
  • Logical navigation patterns
  • Explanations for abbreviations

🆘 Troubleshooting

NVDA Not Working?

  • No sound: Check volume, try different browser
  • Can't find table: Press Tab to navigate manually
  • Weird navigation: Press Insert + Space to toggle browse mode
  • Still broken: Restart NVDA (Ctrl + Alt + N, then restart)

Alternative Testing:

  • macOS: Cmd + F5 for VoiceOver
  • No screen reader: Use Chrome Lighthouse (F12 → Lighthouse → Accessibility)
  • Quick check: Tab through table with eyes closed

✅ Success Criteria

Your improved table passes if a blind user can:

  1. ✅ Immediately understand what the table shows
  2. ✅ Navigate logically between data points
  3. ✅ Find specific information quickly
  4. ✅ Understand all abbreviations and numbers
  5. ✅ Compare data between groups easily

The original table fails most of these criteria, while the improved table should pass all of them!
