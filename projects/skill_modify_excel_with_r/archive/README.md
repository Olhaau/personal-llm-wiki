# Archive Folder

This folder contains development files, experiments, and intermediate outputs that were created during the Excel round-trip formatting fix project.

## Structure

- **`development/`** - Early development scripts and prototypes
- **`experiments/`** - Experimental scripts for testing various approaches  
- **`tests/`** - Test scripts for validation and debugging
- **`old_outputs/`** - Intermediate output files from development process

## Main Project Files (kept in root)

- **`complete_formatting_fix.R`** - Final complete Excel round-trip solution
- **`working_hyperlinks_demo.R`** - Working hyperlink navigation demonstration  
- **`HYPERLINK_FIX_SUMMARY.md`** - Complete documentation of the solution

## Key Outputs (kept in output/)

- **`working_navigation_demo.xlsx`** - Working demonstration with proper navigation
- **`complete_fixed_recreated.xlsx`** - Final recreated file with all fixes
- **`complete_fixed_structure.json`** - Complete JSON structure with formatting
- **`statistischer-bericht-*.xlsx`** - Original and final statistical reports

All archived files were part of the iterative development process to solve Excel formatting and hyperlink preservation issues.
