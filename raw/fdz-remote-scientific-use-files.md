      <h2>Remote Scientific Use Files</h2>
      <span></span>
    </div>
      
            <div property="schema:text">
                <p>Bei Remote Scientific Use Files (Remote-SUF) handelt es sich um faktisch anonyme Datensätze der amtlichen Statistik, die über das Remote Access-System der FDZ genutzt werden können. Das Remote Access-System bietet einen komfortablen Datenzugang aus der eigenen wissenschaftlichen Einrichtung via Remote-Desktop-Anwendung und ermöglicht so eine zeitgemäße und effiziente Datenanalyse.</p><h3>Voraussetzungen</h3><p>Voraussetzung für die Nutzung des Remote Access-Systems sind die erfolgreiche Beantragung der Remote-SUF-Produkte über den <a class="internal icon-arrow-right" href="https://www.forschungsdatenzentrum.de/de/antrag">Nutzungsantrag</a> und der Abschluss eines Nutzungsvertrags. Beantragende Einrichtungen müssen ihren Sitz in Deutschland haben. Auf das Remote Access-System darf nur innerhalb der Räume dieser vertraglich festgelegten wissenschaftlichen Einrichtung mit dienstlicher Hardware zugegriffen werden. Es müssen folgende technische Rahmenbedingungen erfüllt werden:</p><ul><li>Installation eines VPN-Clients und einer Remote-Desktop-Anwendung auf dienstlicher Hardware</li><li>Nutzung eines Hardware-Tokens zur Authentifizierung</li></ul><p>Eine ausführliche Anleitung erhalten Sie im Rahmen der Beratung durch Ihren betreuenden FDZ Standort. Alle Datennutzenden müssen auf die statistische Geheimhaltung nach § 16 Abs. 7 BStatG verpflichtet werden.</p><h3>Das Remote Access-System</h3><p>Nach erfolgreicher Antragstellung und technischer Einrichtung greifen Datennutzende über eine Remote-Desktop-Anwendung auf das Remote Access-System der FDZ zu. Innerhalb des Remote-Systems können die beantragten Daten entweder mit Stata oder R analysiert werden. Das Hoch- oder Herunterladen von Daten durch die Datennutzenden ist ausgeschlossen. Beantragte externe Merkmale werden über die FDZ in das Remote Access-System eingepflegt. Die amtlichen Mikrodaten verbleiben innerhalb des Remote Access-Systems und damit in der Infrastruktur der Statistischen Ämter des Bundes und der Länder. Im Remote Access-System erzeugter und für die Veröffentlichung vorgesehener Output wird durch den betreuenden FDZ Standort auf Geheimhaltung geprüft und im Anschluss via E-Mail den Datennutzenden bereitgestellt.</p><h3>Datenmaterial</h3><p>Aktuell stehen faktisch anonyme Remote-SUF für den <a class="internal icon-arrow-right" href="https://www.forschungsdatenzentrum.de/de/haushalte/mikrozensus">Mikrozensus</a> und die <a class="internal icon-arrow-right" href="https://www.forschungsdatenzentrum.de/de/gesundheit/drg">DRG-Statistik</a> zur Verfügung. Das Angebot wird sukzessive durch weitere Statistiken erweitert. Inhaltliche Details zur Ausgestaltung der Remote-SUF finden Sie in den Metadaten, die auf den jeweiligen Produktseiten zum Download zur Verfügung stehen.</p><h3>Analysesoftware</h3><p>Analysen im Remote Access-System sind syntaxbasiert entweder mit der Analysesoftware Stata oder R möglich. Bei Nutzung von R ist die Anzahl der Datennutzenden pro Projekt auf drei begrenzt.<meta name="viewport" content="width=device-width, initial-scale=1.0"><title>FAQ Muster</title><style>

        </style></p><div class="faq-container"><h3>FAQ - Häufig gestellte Fragen</h3><details><summary>1. Wie erhalte ich Zugang zum Remote Access-System?</summary><div class="faq-content"><p>Nach erfolgreicher Beantragung der Remote-SUF über den <a class="internal icon-arrow-right" href="https://forschungsdatenzentrum.de/de/antrag">Nutzungsantrag</a> erhalten Sie eine ausführliche Handreichung zum System in der u.a. die benötigten Informationen zur Einrichtung eines Accounts und die benötige Software aufgeführt sind.</p></div></details><details><summary>2. Welche Voraussetzungen müssen erfüllt sein?</summary><div class="faq-content"><p>Voraussetzung für die Nutzung ist, dass die beantragende Institution nutzungsberechtigt ist, ihren Sitz in Deutschland hat und dass nur in den Räumen der beantragenden wissenschaftlichen Einrichtungen innerhalb Deutschlands auf das Remote Access-System zugegriffen wird. Alle Datennutzende müssen auf die statistische Geheimhaltung nach § 16 Abs. 7 BStatG verpflichtet werden.</p></div></details><details><summary>3. Welche Statistiken kann ich als Remote-SUF nutzen?</summary><div class="faq-content"><p>Zurzeit gibt es den Remote-SUF für den <a class="internal icon-arrow-right" href="https://forschungsdatenzentrum.de/de/haushalte/mikrozensus">Mikrozensus</a> und die <a class="internal icon-arrow-right" href="https://forschungsdatenzentrum.de/de/gesundheit/drg">DRG-Statistik</a>. Weitere Statistiken folgen sukzessive. Wir informieren Sie über die FDZ-Website sowie den FDZ-Newsletter über neu zur Verfügung stehende Remote-SUF.</p></div></details><details><summary>4. Welche Analysesoftware kann ich für eine Remote-SUF Nutzung verwenden?</summary><div class="faq-content"><p>Für die Analyse kann entweder Stata oder R verwendet werden.</p></div></details><details><summary>5. An wen kann ich mich bei Rückfragen wenden?</summary><div class="faq-content"><p>Ihr betreuender Standort ist Ihr erster Ansprechpartner bei Fragen zum Remote Access-Verfahren. Die richtigen Ansprechpersonen für konkrete Fragen zu einer bestimmten Statistik finden Sie unter <a class="internal icon-arrow-right" href="https://www.forschungsdatenzentrum.de/de/alle-daten">Alle Daten</a> nach einem Klick auf die entsprechende Statistik.</p></div></details></div>
