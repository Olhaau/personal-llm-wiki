<h2>Finding Entries<a class="headerlink" href="#finding-entries" title="Permalink to this headline">¶</a></h2>
<p><strong>find_entries</strong> (title=None, username=None, password=None, url=None, notes=None, path=None, uuid=None, tags=None, string=None, group=None, recursive=True, regex=False, flags=None, history=False, first=False)</p>
<p>Returns entries which match all provided parameters, where <code class="docutils literal notranslate"><span class="pre">title</span></code>, <code class="docutils literal notranslate"><span class="pre">username</span></code>, <code class="docutils literal notranslate"><span class="pre">password</span></code>, <code class="docutils literal notranslate"><span class="pre">url</span></code>, <code class="docutils literal notranslate"><span class="pre">notes</span></code>, <code class="docutils literal notranslate"><span class="pre">path</span></code>, and <code class="docutils literal notranslate"><span class="pre">autotype_sequence</span></code> are strings, <code class="docutils literal notranslate"><span class="pre">string</span></code> is a dict, <code class="docutils literal notranslate"><span class="pre">autotype_enabled</span></code> is a boolean, <code class="docutils literal notranslate"><span class="pre">uuid</span></code> is a <code class="docutils literal notranslate"><span class="pre">uuid.UUID</span></code> and <code class="docutils literal notranslate"><span class="pre">tags</span></code> is a list of strings.  This function has optional <code class="docutils literal notranslate"><span class="pre">regex</span></code> boolean and <code class="docutils literal notranslate"><span class="pre">flags</span></code> string arguments, which means to interpret search strings as <a class="reference external" href="https://www.xml.com/pub/a/2003/06/04/tr.html">XSLT style</a> regular expressions with <a class="reference external" href="https://www.w3.org/TR/xpath-functions/#flags">flags</a>.</p>
<p>The <code class="docutils literal notranslate"><span class="pre">path</span></code> string is a full path to an entry (ex. <code class="docutils literal notranslate"><span class="pre">'foobar_group/foobar_entry'</span></code>).  This implies <code class="docutils literal notranslate"><span class="pre">first=True</span></code>.  All other arguments are ignored when this is given.  This is useful for handling user input.</p>
<p>The <code class="docutils literal notranslate"><span class="pre">string</span></code> dict allows for searching custom string fields.  ex. <code class="docutils literal notranslate"><span class="pre">{'custom_field1':</span> <span class="pre">'custom</span> <span class="pre">value',</span> <span class="pre">'custom_field2':</span> <span class="pre">'custom</span> <span class="pre">value'}</span></code></p>
<p>The <code class="docutils literal notranslate"><span class="pre">group</span></code> argument determines what <code class="docutils literal notranslate"><span class="pre">Group</span></code> to search under, and the <code class="docutils literal notranslate"><span class="pre">recursive</span></code> boolean controls whether to search recursively.</p>
<p>The <code class="docutils literal notranslate"><span class="pre">history</span></code> (default <code class="docutils literal notranslate"><span class="pre">False</span></code>) boolean controls whether history entries should be included in the search results.</p>
<p>The <code class="docutils literal notranslate"><span class="pre">first</span></code> (default <code class="docutils literal notranslate"><span class="pre">False</span></code>) boolean controls whether to return the first matched item, or a list of matched items.</p>
<ul class="simple">
<li>if <code class="docutils literal notranslate"><span class="pre">first=False</span></code>, the function returns a list of <code class="docutils literal notranslate"><span class="pre">Entry</span></code> s or <code class="docutils literal notranslate"><span class="pre">[]</span></code> if there are no matches</li>
<li>if <code class="docutils literal notranslate"><span class="pre">first=True</span></code>, the function returns the first <code class="docutils literal notranslate"><span class="pre">Entry</span></code> match, or <code class="docutils literal notranslate"><span class="pre">None</span></code> if there are no matches</li>
</ul>

<p>where <code class="docutils literal notranslate"><span class="pre">destination_group</span></code> is a <code class="docutils literal notranslate"><span class="pre">Group</span></code> instance.  <code class="docutils literal notranslate"><span class="pre">entry</span></code> is an <code class="docutils literal notranslate"><span class="pre">Entry</span></code> instance. <code class="docutils literal notranslate"><span class="pre">title</span></code>, <code class="docutils literal notranslate"><span class="pre">username</span></code>, <code class="docutils literal notranslate"><span class="pre">password</span></code>, <code class="docutils literal notranslate"><span class="pre">url</span></code>, <code class="docutils literal notranslate"><span class="pre">notes</span></code>, <code class="docutils literal notranslate"><span class="pre">tags</span></code>, <code class="docutils literal notranslate"><span class="pre">icon</span></code> are strings. <code class="docutils literal notranslate"><span class="pre">expiry_time</span></code> is a <code class="docutils literal notranslate"><span class="pre">datetime</span></code> instance.</p>
<p>If <code class="docutils literal notranslate"><span class="pre">expiry_time</span></code> is a naive datetime object (i.e. <code class="docutils literal notranslate"><span class="pre">expiry_time.tzinfo</span></code> is not set), the timezone is retrieved from <code class="docutils literal notranslate"><span class="pre">dateutil.tz.gettz()</span></code>.</p>

<div class="section" id="attachments">
<h2>Attachments<a class="headerlink" href="#attachments" title="Permalink to this headline">¶</a></h2>
<p>In this section, <em>binary</em> refers to the bytes of the attached data (stored at the root level of the database), while <em>attachment</em> is a reference to a binary (stored in an entry).  A binary can have none, one or many attachments.</p>
<p><strong>add_binary</strong> (data, compressed=True, protected=True)</p>
<p>where <code class="docutils literal notranslate"><span class="pre">data</span></code> is bytes.  Adds a blob of data to the database. The attachment reference must still be added to an entry (see below).  <code class="docutils literal notranslate"><span class="pre">compressed</span></code> only applies to KDBX3 and <code class="docutils literal notranslate"><span class="pre">protected</span></code> only applies to KDBX4.  Returns id of attachment.</p>
<p><strong>delete_binary</strong> (id)</p>
<p>where <code class="docutils literal notranslate"><span class="pre">id</span></code> is an int.  Removes binary data from the database and deletes any attachments that reference it.  Since attachments reference binaries by their positional index, attachments that reference binaries with id &gt; <code class="docutils literal notranslate"><span class="pre">id</span></code> will automatically be decremented.</p>
<p><strong>find_attachments</strong> (id=None, filename=None, element=None, recursive=True, regex=False, flags=None, history=False, first=False)</p>
<p>where <code class="docutils literal notranslate"><span class="pre">id</span></code> is an int, <code class="docutils literal notranslate"><span class="pre">filename</span></code> is a string, and element is an <code class="docutils literal notranslate"><span class="pre">Entry</span></code> or <code class="docutils literal notranslate"><span class="pre">Group</span></code> to search under.</p>
<ul class="simple">
<li>if <code class="docutils literal notranslate"><span class="pre">first=False</span></code>, the function returns a list of <code class="docutils literal notranslate"><span class="pre">Attachment</span></code> s or <code class="docutils literal notranslate"><span class="pre">[]</span></code> if there are no matches</li>
<li>if <code class="docutils literal notranslate"><span class="pre">first=True</span></code>, the function returns the first <code class="docutils literal notranslate"><span class="pre">Attachment</span></code> match, or <code class="docutils literal notranslate"><span class="pre">None</span></code> if there are no matches</li>
</ul>
<p><strong>binaries</strong></p>
<p>list of bytestrings containing binary data.  List index corresponds to attachment id.</p>
<p><strong>attachments</strong></p>
<p>list containing all <code class="docutils literal notranslate"><span class="pre">Attachment</span></code> s in the database.</p>
<p><strong>Entry.add_attachment</strong> (id, filename)</p>
<p>where <code class="docutils literal notranslate"><span class="pre">id</span></code> is an int and <code class="docutils literal notranslate"><span class="pre">filename</span></code> is a string.  Creates a reference using the given filename to a database binary.  The existence of a binary with the given id is not checked.  Returns <code class="docutils literal notranslate"><span class="pre">Attachment</span></code>.</p>
<p><strong>Entry.delete_attachment</strong> (attachment)</p>
<p>where <code class="docutils literal notranslate"><span class="pre">attachment</span></code> is an <code class="docutils literal notranslate"><span class="pre">Attachment</span></code>.  Deletes a reference to a database binary.</p>
<p><strong>Entry.attachments</strong></p>
<p>list of <code class="docutils literal notranslate"><span class="pre">Attachment</span></code> s for this Entry.</p>
<p><strong>Attachment.id</strong></p>
<p>id of data that this attachment points to</p>
<p><strong>Attachment.filename</strong></p>
<p>string representing this attachment</p>
<p><strong>Attachment.data</strong></p>
<p>the data that this attachment points to.  Raises <code class="docutils literal notranslate"><span class="pre">BinaryError</span></code> if data does not exist.</p>
<p><strong>Attachment.entry</strong></p>
<p>the entry that this attachment is attached to</p>
<div class="code python highlight-default notranslate"><div class="highlight"><pre><span></span><span class="gp">&gt;&gt;&gt; </span><span class="n">e</span> <span class="o">=</span> <span class="n">kp</span><span class="o">.</span><span class="n">add_entry</span><span class="p">(</span><span class="n">kp</span><span class="o">.</span><span class="n">root_group</span><span class="p">,</span> <span class="n">title</span><span class="o">=</span><span class="s1">&#39;foo&#39;</span><span class="p">,</span> <span class="n">username</span><span class="o">=</span><span class="s1">&#39;&#39;</span><span class="p">,</span> <span class="n">password</span><span class="o">=</span><span class="s1">&#39;&#39;</span><span class="p">)</span>

<span class="gp">&gt;&gt;&gt; </span><span class="n">kp</span><span class="o">.</span><span class="n">binaries</span>

<div class="section" id="miscellaneous">
<h2>Miscellaneous<a class="headerlink" href="#miscellaneous" title="Permalink to this headline">¶</a></h2>
<p><strong>read</strong> (filename=None, password=None, keyfile=None, transformed_key=None)</p>
<p>where <code class="docutils literal notranslate"><span class="pre">filename</span></code>, <code class="docutils literal notranslate"><span class="pre">password</span></code>, and <code class="docutils literal notranslate"><span class="pre">keyfile</span></code> are strings.  <code class="docutils literal notranslate"><span class="pre">filename</span></code> is the path to the database, <code class="docutils literal notranslate"><span class="pre">password</span></code> is the master password string, and <code class="docutils literal notranslate"><span class="pre">keyfile</span></code> is the path to the database keyfile.  At least one of <code class="docutils literal notranslate"><span class="pre">password</span></code> and <code class="docutils literal notranslate"><span class="pre">keyfile</span></code> is required.  Alternatively, the derived key can be supplied directly through <code class="docutils literal notranslate"><span class="pre">transformed_key</span></code>.</p>
<p>Can raise <code class="docutils literal notranslate"><span class="pre">CredentialsError</span></code>, <code class="docutils literal notranslate"><span class="pre">HeaderChecksumError</span></code>, or <code class="docutils literal notranslate"><span class="pre">PayloadChecksumError</span></code>.</p>
<p><strong>save</strong> (filename=None)</p>
<p>where <code class="docutils literal notranslate"><span class="pre">filename</span></code> is the path of the file to save to.  If <code class="docutils literal notranslate"><span class="pre">filename</span></code> is not given, the path given in <code class="docutils literal notranslate"><span class="pre">read</span></code> will be used.</p>
<p><strong>password</strong></p>
<p>string containing database password.  Can also be set.  Use <code class="docutils literal notranslate"><span class="pre">None</span></code> for no password.</p>
<p><strong>keyfile</strong></p>
<p>string containing path to the database keyfile.  Can also be set.  Use <code class="docutils literal notranslate"><span class="pre">None</span></code> for no keyfile.</p>
<p><strong>version</strong></p>
<p>tuple containing database version.  e.g. <code class="docutils literal notranslate"><span class="pre">(3,</span> <span class="pre">1)</span></code> is a KDBX version 3.1 database.</p>
<p><strong>encryption_algorithm</strong></p>
<p>string containing algorithm used to encrypt database.  Possible values are <code class="docutils literal notranslate"><span class="pre">aes256</span></code>, <code class="docutils literal notranslate"><span class="pre">chacha20</span></code>, and <code class="docutils literal notranslate"><span class="pre">twofish</span></code>.</p>
<p><strong>create_database</strong> (filename, password=None, keyfile=None, transformed_key=None)</p>
<p>create a new database at <code class="docutils literal notranslate"><span class="pre">filename</span></code> with supplied credentials.  Returns <code class="docutils literal notranslate"><span class="pre">PyKeePass</span></code> object</p>
