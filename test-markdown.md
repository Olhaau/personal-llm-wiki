# Test Markdown Links

Current date syntax from our files:
- **File Modified**: [2024-11-17]
- **Last Updated**: [2024-11]

These are reference-style markdown links. Without link definitions, they render as:
- **File Modified**: [2024-11-17] (appears as plain text)
- **Last Updated**: [2024-11] (appears as plain text)

If we want them to be actual links, we need either:
1. Link definitions at the bottom: [2024-11-17]: https://example.com
2. Inline links: [2024-11-17](https://example.com)
3. Or just use plain text: 2024-11-17
