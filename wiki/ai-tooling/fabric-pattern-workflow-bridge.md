# Fabric Pattern Workflow Bridge

## Summary

Fabric installation options provide the execution base for running pattern workflows from a local shell environment [[raw/fabric-one-line-install-recommended.md]]. The documented alias convention (`fabric-ai` to `fabric`) reduces command friction when patterns are used repeatedly across automation and prompting tasks [[raw/fabric-one-line-install-recommended.md]].

## Details

After installation, users can standardize command invocation through package-manager aliases or direct binary usage, which supports repeatable CLI workflows that call prompt patterns and related tooling [[raw/fabric-one-line-install-recommended.md]]. This execution layer complements skill-oriented prompt designs that separate high-level instructions from specialized operational steps in other topic pages [[wiki/prompt-engineering/agent-skills-progressive-disclosure.md]].
