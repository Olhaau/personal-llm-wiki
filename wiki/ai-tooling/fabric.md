## Summary

Fabric is an open-source framework that organizes reusable AI prompts (called patterns) around real-world tasks, with a strong CLI workflow for day-to-day use [[raw/fabric-readme.md]]. The project positions itself as a solution to an AI integration problem: many model interfaces exist, but operational reuse and organization are hard [[raw/fabric-readme.md]].

## Details

Fabric supports direct command-line execution of patterns, setup workflows, model and vendor listing, URL scraping, and optional REST API serving through `fabric --serve` [[raw/fabric-readme.md]]. Installation paths include one-line scripts for Unix and Windows, package managers, and source installation via Go [[raw/fabric-readme.md]].

The README emphasizes reusable pattern authoring in Markdown and task decomposition as a practical method for applying AI to specific workflows [[raw/fabric-readme.md]].
