# BSI Standards 200 Series for Security Governance

The BSI 200-series provides governance and management scaffolding for information security programs:
- 200-1 defines ISMS fundamentals.
- 200-2 defines IT-Grundschutz methodik with basis, kern, and standard absicherung.
- 200-3 defines risk management integration for IT-Grundschutz environments.
- 200-4 defines business continuity management integration.

For software development, these standards set the process and assurance context in which detailed bausteine requirements are applied.
