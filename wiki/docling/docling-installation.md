# Docling Installation

## Summary

Docling installation for the documented assistant workflow uses `pip` and includes both `docling` and `docling-core` packages [[raw/docling-agent-skill-docling-document-intelligence.md]]. This setup provides the `docling` CLI needed for Markdown and JSON conversion commands [[raw/docling-agent-skill-docling-document-intelligence.md]].

## Details

The quick-start sequence in the source installs dependencies with `pip install docling docling-core` before any conversion or quality-evaluation steps [[raw/docling-agent-skill-docling-document-intelligence.md]]. After installation, the same workflow runs CLI conversions and optional evaluator scripts, which makes installation the required first step for all downstream examples in the topic [[raw/docling-agent-skill-docling-document-intelligence.md]].
