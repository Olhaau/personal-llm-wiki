# Docling Integrations and Usage Modes

Docling is exposed through both CLI and Python APIs, with documented quickstart flows for each:
- CLI conversion for URL/local sources.
- Python `DocumentConverter` usage for programmatic pipelines.

The sources also emphasize integration-level usage:
- framework adapters for common AI stacks (for example LangChain, LlamaIndex, Haystack),
- agent-oriented usage via an MCP server and assistant skill examples,
- specialized recipe sets for extraction, chunking/serialization, and retrieval workflows.

This suggests a layered adoption path: start with direct conversion, then evolve into reusable ingestion and retrieval infrastructure in larger agent systems.
