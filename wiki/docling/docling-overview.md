# Docling Overview

Docling is positioned as a document processing stack designed for gen-AI pipelines. The core claim is that it standardizes parsing across diverse document/media formats and provides a unified representation that can be exported for downstream tasks.

The documentation and README both emphasize three core properties:
- breadth of ingestion formats (documents, media, and structured formats),
- high-fidelity document understanding (especially PDF/layout-aware parsing),
- ecosystem interoperability (framework integrations plus CLI/Python APIs).

In the source set, Docling appears both as a standalone toolkit and as infrastructure for larger assistant workflows (for example, agent-skill examples and RAG pipelines).
