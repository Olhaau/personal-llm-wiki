# Docling

## Summary

Docling is a document-processing toolkit that converts heterogeneous inputs into structured, workflow-ready outputs for downstream automation and LLM pipelines [[raw/docling-docs.md]]. The project supports broad format coverage and exposes both CLI and Python usage modes for ingestion workflows [[raw/docling-quickstart.md]]. Integration guidance and examples position Docling as an upstream component for retrieval and synthesis stacks [[raw/docling-examples.md]].

## Details

Pipeline capabilities include conversion to markdown and other structured formats, making normalized source creation reproducible for later compile/query operations [[raw/docling-github.md]]. Quickstart syntax patterns and integration recipes support operational deployment in local tools, agents, and orchestration chains [[raw/docling-quickstart.md]].
