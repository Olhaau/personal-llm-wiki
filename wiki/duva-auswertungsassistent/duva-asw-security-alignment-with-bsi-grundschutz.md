# DUVA ASW Security Alignment with BSI Grundschutz

For the DUVA ASW successor, security requirements can be operationalized by connecting DUVA procurement and operating context with the BSI IT-Grundschutz software-security structure:

- DUVA procurement context defines the need for a new evaluation component.
- DUVA operating materials frame practical usage and deployment context.
- BSI 200-series provides governance, methodik, risk, and continuity framing.
- BSI software bausteine context (CON.8 and APP.6) provides software-lifecycle security control orientation.

This creates a usable bridge from DUVA delivery objectives to verifiable security requirements for implementation and operations.
