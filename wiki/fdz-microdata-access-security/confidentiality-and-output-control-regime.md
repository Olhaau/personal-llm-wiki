# Confidentiality and Output Control Regime

RDC confidentiality controls are centered on preventing publication of results that allow inference about individual cases.

Operationally, this means:
- confidentiality criteria are applied to produced outputs,
- non-compliant outputs are blocked or rejected,
- blocked values can propagate to later result sets,
- users are expected to prepare compliant analysis code and outputs.
