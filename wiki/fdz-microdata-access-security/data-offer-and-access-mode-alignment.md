# Data Offer and Access Mode Alignment

FDZ product discovery and FDZ access governance are tightly coupled: the available data offer determines feasible analysis paths, while the selected access mode determines legal/technical boundaries.

- Topic and sitemap navigation identifies relevant products and metadata entry points.
- Access-mode choice (Campus/PUF/SUF/Remote-SUF) determines institutional prerequisites, environment constraints, and release workflows.
- This coupling reduces misuse risk by binding data detail and usage context to explicit controls.
