# FDZ Data Supply Portfolio and Access Formats

FDZ exposes a broad portfolio of statistical products via topic hubs and product pages, while access is separated into distinct usage formats with different anonymity and governance requirements.

- Data portfolio: topic pages (for example Gesundheit, Haushalte, Steuern, AFiD) act as entry hubs to concrete product pages.
- Access formats: Campus Files and PUF support strongly anonymized use, while SUF and Remote-SUF support richer analysis under stricter controls.
- Operational implication: project planning must align research scope with the permitted access mode, location constraints, and output controls.
