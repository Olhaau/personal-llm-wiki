# fdz-microdata-access-security

## Summary

FDZ microdata access security combines legal entitlement checks, controlled access modes, anonymity classes, and confidentiality controls for research data use [[raw/fdz-access-to-microdata.md]]. The workflow constrains processing from request intake to publication-ready output release through contractual and procedural safeguards [[raw/fdz-request-for-access.md]]. Data-protection duties remain explicit across the lifecycle under the published privacy notice and usage rules [[raw/fdz-data-privacy-notice.md]].

## Details

Access paths (for example Campus Files, Public Use Files, Scientific Use Files, and Remote Scientific Use Files) apply different control levels based on sensitivity and re-identification risk [[raw/fdz-public-use-files.md]]. Confidentiality review and output checking are mandatory before release, and statistical disclosure control methods such as Cell-Key support risk reduction for tabular outputs [[raw/fdz-confidentiality.md]].
