# Remote Access Technical and Organizational Safeguards

Remote SUF usage combines legal access conditions with technical and organizational safeguards that reduce data leakage risk.

Key safeguards include:
- institution-location and on-premise usage constraints,
- authentication controls (hardware token) and remote desktop workflow,
- prohibition of direct upload/download by users,
- retention of official microdata within RDC infrastructure,
- confidentiality review before output release.
