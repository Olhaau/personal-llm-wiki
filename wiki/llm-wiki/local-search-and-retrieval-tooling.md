# Local Search and Retrieval Tooling

As wiki size grows, index-only navigation becomes insufficient. The sources highlight local retrieval tooling (notably qmd) as a scale path:
- hybrid lexical + vector retrieval,
- optional reranking,
- CLI and MCP interfaces for agent integration,
- structured outputs (`--json`, `--files`) for agentic workflows.

The role of these tools is supportive: retrieval quality improves, while compilation and synthesis still happen in wiki workflows.
