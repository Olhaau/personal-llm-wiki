# FDZ Anonymity levels

The page defines absolute, factual, and formal anonymity and links each level to allowed access contexts.

Key points:
- absolute anonymity supports broad external use (for example PUF/Campus Files),
- factual anonymity allows scientific use with stronger access restrictions,
- formal anonymity is available in specially protected settings (safe centres/remote execution),
- legal framing references section 16 BStatG and institution eligibility requirements.
