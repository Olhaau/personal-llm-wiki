# FDZ Confidentiality

The page describes the RDC obligation to ensure statistical confidentiality under the Federal Statistics Act.

Core controls:
- output may not enable conclusions about individual cases,
- every on-site result is checked against confidentiality criteria,
- blocked values can propagate to follow-up analyses,
- non-compliant code or result release can be rejected,
- regulations and sample code are provided to enforce compliant analysis workflows.
