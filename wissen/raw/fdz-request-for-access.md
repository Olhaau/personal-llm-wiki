# FDZ Request for access

The page defines mandatory information for microdata access applications and links request processing to terms/regulations.

Required elements include institution and user identity data, project/method descriptions, requested statistics/years, and access modes.

The process explicitly ties access requests to:
- acceptance of terms of use and regulations,
- data-protection information,
- RDC right to reject output checks/releases when rules are not fulfilled.
