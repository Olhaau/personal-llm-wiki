## Requesting microdata

**The access to official statistics microdata has to be applied for. For this, you must use the application form provided by the RDC. The following information is necessary for the application for access:**

-   Name and address of the applying scientific institution
-   Name and contact data of all data users
-   Project description and statistical methods to be applied
-   Requested statistics and survey years
-   Requested ways of access
-   If a cooperation is planned: name of cooperating institution(s)
-   If data is to be merged: detailed [description of the process](/sites/default/files/Template_RDC_process_description_v2.docx)

We advise researchers who make an application for access for the first time to consult the RDC staff in advance. A detailed consultation usually results in a faster processing of the request.

You can, in general, [contact](/en/contact) any RDC location for consultation. You find the correct contact person for specific questions on a given statistic on [All Data](/en/all-data) after clicking on that statistic.

Please inform yourself about the [terms of use and regulations](/en/terms-use) on the analysis of microdata in the RDC and read our [note on data protection](/en/data-protection) for more information on the use of your data within the processing of your request for access.

Please use the application form below for your request for access. The most comfortable way to request access to the microdata is the online version of the request form. The form itself is only available in German but can be translated using commonly available browser add-ons. You can save the data you have entered to continue editing it at a later time and you can print the request for access for your records. If that does not work for you, you can also download and fill in the English paper version and sent it to us via postal services, fax or e-mail.

I have read and accept the terms of use and the regulations. I am informed that the RDC can make use of the option to reject the check resp. release of output if the regulations are not fulfilled.
