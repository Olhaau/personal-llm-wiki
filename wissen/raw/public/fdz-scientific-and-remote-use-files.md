# FDZ Scientific Use Files und Remote Scientific Use Files

Die FDZ-Seiten zu Scientific Use Files (SUF) und Remote Scientific Use Files (Remote-SUF) beschreiben zwei zentrale Zugangsmodi fuer faktisch anonyme Mikrodaten.

Kernaussagen zu SUF:
- SUF sind standardisierte, faktisch anonyme Datensaetze fuer wissenschaftliche Forschung.
- Nutzung ausserhalb geschuetzter Raeume ist moeglich, aber an rechtliche und institutionelle Bedingungen gebunden.
- Bereitstellung erfolgt nach Nutzungsantrag ueber Downloadservice.

Kernaussagen zu Remote-SUF (Quelle: Remote-SUF-Seite):
- Zugriff erfolgt ueber ein Remote-Access-System aus der wissenschaftlichen Einrichtung.
- Daten verbleiben in der Infrastruktur der Statistischen Aemter.
- Up-/Download durch Nutzende ist ausgeschlossen; Output wird auf Geheimhaltung geprueft.
- Als aktuelle Beispiele werden Mikrozensus und DRG-Statistik genannt.

Der Zugang ist in beiden Faellen an Antrag, vertragliche/regulatorische Bedingungen und Geheimhaltungsverpflichtungen gekoppelt.
