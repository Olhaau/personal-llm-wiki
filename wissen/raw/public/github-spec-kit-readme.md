An open source toolkit that allows you to focus on product scenarios and predictable outcomes instead of vibe coding every piece from scratch.

## What is Spec-Driven Development?

Spec-Driven Development flips the script on traditional software development. Specifications become executable, directly generating working implementations rather than just guiding them.

## Get Started (selected commands)

```bash
specify init <PROJECT_NAME>
/speckit.constitution
/speckit.specify
/speckit.plan
/speckit.tasks
/speckit.implement
```

## Supported integration note

Spec Kit supports many AI coding agents and provides both slash-command and skill-based integration flows.

## Core philosophy (source)

- Intent-driven development where specifications define the "what" before the "how"
- Multi-step refinement rather than one-shot code generation
- Heavy reliance on advanced AI model capabilities for specification interpretation
