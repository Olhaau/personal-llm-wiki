# IT-Grundschutz Bausteine for Software Development

Within Edition 2023 of the IT-Grundschutz-Kompendium, software-development execution is primarily represented by:
- CON.8 Software-Entwicklung (security aspects for in-house software development preparation and execution).
- APP.6 Allgemeine Software (secure lifecycle requirements for deployed software).

Related bausteine from the same source list can complement this scope, including APP.7 (individual software) and CON.10 (web application development).
