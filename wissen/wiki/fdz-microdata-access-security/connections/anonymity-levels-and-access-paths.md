# Anonymity Levels and Access Paths

RDC access paths are directly coupled to the anonymity level of data.

- Absolute anonymity enables broader access models (for example PUF and Campus Files).
- Factual anonymity supports scientific use under stricter institutional and usage controls.
- Formal anonymity is tied to protected environments such as safe centres and remote execution.

This mapping acts as a security boundary between analytic utility and disclosure risk.
