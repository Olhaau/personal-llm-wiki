# Docling Pipeline Capabilities

Docling describes a pipeline that combines format parsing, structure reconstruction, and export-oriented serialization. The capability surface in the ingested sources includes:

- multi-format parsing (PDF, DOCX, PPTX, XLSX, HTML, text/markdown variants, images, and selected media formats),
- layout- and structure-aware processing (reading order, table structure, formulas/code, and OCR-enriched paths),
- multiple output formats (Markdown, HTML, JSON, DocTags, and related exports),
- optional model-assisted enrichment (VLM and ASR pathways).

From the examples index, the project also frames these capabilities as composable recipes (conversion, chunking, extraction, picture annotation, RAG, and GPU optimization), indicating that the pipeline is intended to be configured rather than treated as a single fixed conversion command.
