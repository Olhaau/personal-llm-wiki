# fdz-microdata-access-security

`fdz-microdata-access-security` is the topic-level concept for the security and governance model of RDC microdata use: legal entitlement, controlled access modes, anonymity-based data classes, confidentiality checks, and GDPR-based processing duties.

It captures how microdata use is constrained from request intake to result release.
